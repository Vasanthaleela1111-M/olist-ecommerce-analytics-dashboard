# Olist Brazilian E-Commerce Analytics Submission Package

This folder contains the complete, competition-ready submission artifacts for the Olist Hackathon project.

## Directory Structure
- Olist_Hackathon_Notebook.ipynb: End-to-end master Jupyter Notebook.
- Olist_Analysis_Report.md / .pdf: Comprehensive 14-section executive report.
- Olist_Executive_Presentation.md / .pdf: 10-slide executive presentation deck.
- Olist_3_Minute_Script.txt: Spoken presentation script (3:00 timing breakdown).
- Olist_Master_Dataset.csv: Validated master dataset ( = 99,441$ rows, 58 columns).
- methodology.md: Methodological governance audit and non-causal controls.
- README.md: Submission package guide and reproduction instructions.
